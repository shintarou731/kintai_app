## 実装内容

### データ

### 依存関係
- `Gemfile` に `gem "csv", "~> 3.3"` を足した。
  - Ruby 3.4 では `csv` が標準添付ではなくなり、Bundler の下では `require "csv"` が失敗するため。
  - 入っていた csv 3.3.2 を使った（`bundle install --local`。ネットワークは使っていない）。`Gemfile.lock` に csv 3.3.2 が加わった（checksum の欄は空）。

### モデル（すべて新規。ただし `LeaveRequest#label_on` は既存のクラスに追加）
| クラス | 役割 |
|---|---|
| `AttendanceCsv`（モジュール） | CSV の書き方の決まり。BOM・CRLF・エスケープ（csv gem、RFC 4180）・数式の扱い・時間・日数・時刻・日付の書き方・ファイル名の月度。 |
| `MonthlySummaryCsv` | 従業員別の集計。`MonthlySummary#rows` から作る（画面の表と同じ値）。 |
| `MonthlyDailyCsv` | 日別の明細。`MonthlySummary#rows` の各行の `monthly.days` から作る（勤怠履歴・日別の勤怠の画面と同じ値）。 |
| `LeaveRequest#label_on(date)` | 勤怠履歴の休暇の表示（「有給（全日）」「…・申請中」「…・取消申請中」「休日（有給の期間中）」）。勤怠履歴のバッジ（`attendance_leave_badges`）と CSV で共用するため、ヘルパーの文言をここへ移した（表示は変わらない）。 |

締め済みの月度は、`MonthlySummary` が締めた時点の値（`MonthlyClosingEntry`・`ClosedMonthlyAttendance`）を返すので、CSV も自動的に固定した値になる。

### コントローラ・ルート
- `Admin::MonthlyExportsController#show`（`Admin::BaseController` の子。管理者だけ）
  - `GET /admin/monthly/exports/summary.csv?month=2026-11`：従業員別の集計
  - `GET /admin/monthly/exports/daily.csv?month=2026-11`：日別の明細
  - `:id` は `summary|daily` だけ（それ以外は 404）。不正な月は月次集計へ戻してメッセージを出す。
  - `send_data`（`disposition: attachment`、`text/csv; charset=utf-8`）。`Cache-Control: no-store`（個人の勤怠のため）。

### 画面

  - ボタン2つ：「従業員別の集計（N名）」「日別の明細（N名 × 30日）」。`download` 属性にファイル名、`data-turbo=false`。

  - 書式の説明（UTF-8・BOM 付き、「時:分」と「分」の列、勤務の無い日も出すこと、数式の扱い）。
  - 375px ではボタンが1行ずつ全幅になる。

## 決めた扱い

| 項目 | 決めた扱い |
|---|---|
| **文字コード** | UTF-8、先頭に BOM（EF BB BF）。Excel でダブルクリックで開いても文字化けしない。Shift_JIS は、Excel 以外のソフトや環境依存文字（はしご高など）で困るため選ばなかった。 |
| **改行** | CRLF（Excel・多くの給与ソフトの期待する形。RFC 4180 と同じ）。値の中の改行は LF のまま、ダブルクォートの中に入れる。 |
| **エスケープ** | RFC 4180（csv gem）。カンマ・改行・ダブルクォートを含む値は、全体を `"` で囲み、中の `"` は `""` にする。それ以外の値は囲まない。 |
| **CSV インジェクション** | 文字列の値が `=` `+` `-` `@`、タブ、CR で始まるときは、先頭に `'` を付ける（例：`=HYPERLINK(...)` → `'=HYPERLINK(...)`）。OWASP の推奨と同じ。見出しにも同じ処理をかける。<br>- 数値（分・回数・日数・従業員ID）は数値のまま出すので変わらない（負の値は出ない）。<br>- 途中にある `=` などはそのまま（例：「山田=太郎」）。<br>- 欠点：名前が本当に `-` で始まる人は、CSV 上は `'-` になる（Excel で開くと `'` は表示されないが、テキストとして読むソフトでは `'` が残る）。 |
| **時間の表記** | 画面と同じ「時:分」（例 `7:45`、`28:25`）の列と、「分」の整数（`465`）の列を **隣り合わせで両方** 出す（列名は「実働」「実働（分）」）。<br>- 「時:分」は画面と見比べやすい。Excel では `28:25` が時刻（日付またぎ）と解釈されることがあるため、計算・給与ソフトへの取り込みには「分」の列を使う想定。<br>- 小数の時間（7.75）は、端数（1/60）が丸めで画面と食い違うため出さない。必要なら「分 ÷ 60」で作れる。 |
| **日数・回数** | 日数は数値（`0.5`、`2`）、回数は整数。単位は見出しに書く（「有給取得（日）」「遅刻（回）」）。 |
| **時刻・日付** | 出勤・退勤は画面と同じ `09:00`。日付は `2026/11/23`（Excel が日付として読める形）。 |
| **日付をまたいだ退勤** | 画面と同じく「翌」を付ける（例 `翌01:00`）。 |
| **勤務の無い日の行** | **出す**。月度のすべての日を、従業員ごとに1行ずつ並べる（画面の勤怠履歴と同じ）。<br>- 休暇・欠勤（シフトがあるのに打刻が無い日）・休日を拾いやすく、従業員ごとの行数がそろうため。<br>- 勤務の無い日は、出勤〜深夜の欄が空欄。不要なら「出勤」の列で絞り込めば勤務日だけになる。 |
| **退勤漏れの日** | 退勤は「未打刻」、休憩・実働・残業・深夜は空欄（画面の「—」。時間を計算できないため合計にも入らない）、状態は「退勤漏れ」。 |
| **勤務中・休憩中の日** | 書き出した時点までの時間（画面と同じ）。退勤は空欄、状態は「勤務中」「休憩中」。 |
| **日別の明細の列** | 指定の列（従業員名・日付・出勤・退勤・休憩・実働・残業・深夜・休暇・遅刻/早退/欠勤）に加えて、従業員ID・曜日・休日（祝日名／土曜／日曜）・予定（シフト）・時間の「分」の列・遅刻（分）・早退（分）・状態（勤務中／休憩中／退勤漏れ）。 |
| **休暇の欄** | 画面のバッジと同じ文言。承認済み「有給（午前半休）」、承認待ち「…・申請中」、取消申請中「…・取消申請中」、期間中の休日「休日（有給の期間中）」。複数あれば「、」でつなぐ。締め済みの月度は、締めた時点に有効だった休暇だけ（画面と同じ）。 |
| **遅刻・早退・欠勤の欄** | 画面のバッジと同じ文言（「遅刻 0:05、早退 0:30」「欠勤」）。遅刻・早退の分は別の列にも数値で出す。 |
| **従業員別の集計の列** | 月度・期間・締め（締め済み／未締め）・従業員ID・氏名・アカウント（有効／無効）・出勤日数・総実働・残業・深夜・休日勤務（それぞれ「時:分」と「分」）・有給取得（日）・遅刻・早退・欠勤（回）・**欠勤の休暇（日）**（スプリント14の評価の所見を受けて別の列にした）・退勤漏れ（件）。<br>月度・期間・締めは全行に入れる（複数月のファイルをつなげても区別できるように）。 |
| **合計の行** | 出さない（取り込むときに従業員の行と混ざるため）。 |
| **出す従業員** | 月次集計の表と同じ（有効な全員＋記録のある無効なユーザー。締め済みの月度は締めた時点の顔ぶれ）。 |
| **ファイル名** | 「勤怠集計_2026年11月度.csv」「勤怠明細_2026年11月度.csv」。<br>- 月末締めでも「月度」と書く（仕様の例どおり）。<br>- **未締めの月度は「_未締め」を付ける**（例「勤怠集計_2026年11月度_未締め.csv」）。締める前のファイルを確定値と取り違えないため。<br>- `Content-Disposition` は Rails の `send_data` が `filename="..."`（ASCII に置き換えた予備）と `filename*=UTF-8''%E5%8B%A4...`（RFC 6266/5987）の両方を付ける。今のブラウザは `filename*` を使う。リンクにも `download` 属性でファイル名を付けた。 |
| **権限** | `Admin::BaseController` の判定で、従業員はホームへ戻す（302。CSV の中身・`Content-Disposition` は返さない）。ログインしていなければログイン画面へ。 |

## 既知の問題・懸念
- **実際の Excel・給与ソフトでは開いていない**（Windows の Excel が手元で自動操作できないため）。BOM・CRLF・RFC 4180 のエスケープは自動テストで確かめた。
- **Excel での「時:分」の列**：`28:25` のような24時間を超える値は、Excel が時刻（日付つき）として解釈し、表示が変わることがある。計算には「分」の列を使う前提にした（画面の説明には「給与ソフトに取り込みやすい『分』の列」とだけ書いており、Excel の解釈までは書いていない）。
- **数式の対策で `'` を付けた値**：テキストとして読むソフトでは、名前の先頭に `'` が残る（`-` で始まる名前などの場合）。
- **`Gemfile.lock` の csv の checksum が空**：`bundle install --local` で入れたため。ネットワークのある環境で `bundle lock` し直すと埋まる。
- **時間・遅刻/早退の文言を画面と CSV の2か所に持っている**（`format_duration` と `AttendanceCsv.duration`、`ShiftChecksHelper` と `MonthlyDailyCsv::MARK_LABELS`）。テストで一致を確かめているが、片方だけ変えると食い違う。
- **大人数のとき**：CSV はメモリ上で作ってから返す（ストリーミングしない）。想定の数十名 × 31日（千数百行）では問題ないが、数千名になると遅くなる。
- **未締めの月度の CSV** は、書き出した時点の値（勤務中の日は、その時点までの時間）。注意書きとファイル名の「_未締め」で知らせている。
- 一時ファイル `tmp/s15_smoke.rb`（読み取りだけの確認用）を残している。不要なら削除してよい。
