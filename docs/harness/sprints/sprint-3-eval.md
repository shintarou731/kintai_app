# スプリント 3 評価：出勤・退勤の打刻（F3）

## 判定：合格

F3 の受け入れ基準 8 項目はすべてブラウザ操作で確認できた。重大なバグはない。
ただし「勤務中の実働時間がリアルタイムで進む」というレポートの記述は事実と違い、再読み込みするまで実働時間が止まったままになる（中程度のバグ。受け入れ基準は「表示される」なので未達とはしない）。次のスプリントの前に直すことを強く勧める。

### 24時間ルール（generator 独自ルール）についての所見
- F3 の受け入れ基準（22:00出勤→翌2:00退勤を翌日に退勤できる、同じ日に2回出勤できない）とは矛盾しない。24時間を超える連続勤務は通常の業務では想定しにくく、F5 の「退勤漏れ」表示へつなげる仕組みとして妥当。
- ただし注意点がある。**前日の退勤を押し忘れた人が、翌日 24時間以内に出社した場合**（例：11/23 09:00 出勤・退勤忘れ → 11/24 08:30 出社）、ホームは「11/23 の勤務の続き」として「勤務中」になり「出勤」が押せない。本人は「退勤」（23.5時間の勤務として記録）を押してから出勤するしかなく、誤った長時間勤務が記録されやすい。F7（修正申請）で直せる前提だが、後続スプリントで「一定時間（例：16時間）を超えた勤務中の状態では、退勤するか退勤漏れとして扱うかを選べる」等の案内を検討するとよい。合否には影響させない。

## バグ（重要度順）
1. **[中]** 勤務中の実働時間がリアルタイムで進まない（レポートの「勤務中は実働時間がリアルタイムで進む」は事実と異なる）
   - 再現手順：従業員でログイン →「出勤」→ ホームを開いたまま 1分半待つ。
   - 期待される動作：「今日の勤務」の実働時間が 0:00 → 0:01 と進む。
   - 実際の動作：19:01:13 出勤、時計表示 19:02:37 の時点でも「0:00（勤務中）」のまま。再読み込みすると「0:01」になる。
   - 原因：`data-controller="clock"` は打刻カード（`section.card.punch`）に付いているが、`data-clock-target="elapsed"` の span は別の `section`（今日の勤務）にあり、Stimulus のスコープ外。ブラウザで `controllerElement.contains(elapsedElement)` が `false` を返すことを確認した。system テストもこれを検出していない。
2. **[軽微]** 退勤時刻の再送信エラーで、別の日のメッセージが出ることがある
   - 再現手順：double（11/23 22:00〜11/24 02:00 の勤務あり、11/24 は未出勤）で、11/24 19:01 に `/clock_out` を POST。
   - 期待される動作：「出勤していないため、退勤できません。」
   - 実際の動作：「すでに退勤しています（02:00 に退勤）。」（今日 0 時以降に退勤した前日勤務を拾っている）。通常はボタンが disabled なので実害は小さい。
3. **[軽微]** 1280px で打刻カードが左寄せ（幅 720px 程度）になり、画面右側が大きく空く。仕様の「ホーム画面の中央に現在時刻を大きく表示」に対して、ページ中央からずれて見える。また打刻カードと「今日の勤務」カードの間に余白がなくくっついて見える。
4. **[軽微]** 日付またぎの勤務で、出勤 22:00・退勤 02:00 と表示されつつ実働「3:59」になる（秒の切り捨て）。計算は正しいが、利用者には「4:00 では？」と見える。F5 で分単位の扱いを統一する際に検討を。

## 改善点（ジェネレーターへの具体的な指示）
- `app/views/home/show.html.erb` で `data-controller="clock"` と `data-clock-server-now-value` を、打刻カードと「今日の勤務」カードの両方を包む要素（例：`div.page`）に移す。または実働時間の要素を別の小さな Stimulus コントローラにする。
- `test/system/punching_test.rb` に「出勤後、`travel` などで時刻を進めずとも `data-started-at` を過去にした状態で数秒待つと実働時間の表示が変わる」ことを確認するテストを追加する（例：出勤済みの勤怠を 2分前の `clock_in_at` で作ってホームを開き、表示が `0:02` 以上になることと、JS が更新していることを `data-started-at` 経由で検証）。
- `TimeClock#cannot_clock_out_message` は「今日を勤務日とする勤務の退勤」または「直前に打刻された勤務」で判定し、前日勤務の退勤時刻を「すでに退勤しています」と返さないようにする（未出勤なら「出勤していないため、退勤できません」）。
- 1280px 以上では `.page--narrow` を中央寄せ（`margin-inline: auto`）にし、カード間に `gap`／`margin-top` を入れる。
- 24時間ルールについて、前日の退勤忘れのまま翌日出社した場合の案内（例：出勤から 16時間超なら「前日の退勤を押し忘れていませんか？」の注意表示）を検討する（任意）。
