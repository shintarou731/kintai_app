# スプリント 5 実装レポート：自分の勤怠履歴（月次）（F5）

## 実装内容

マイグレーションは追加していない（既存テーブルの読み取りだけ）。開発 DB は ユーザー4・勤怠4・休憩4 のまま。

- **勤務ルール（F6 で差し替える前提）** `app/models/work_rules.rb`
  - DB を持たない小さなクラス。`WorkRules.current` が初期値（所定労働時間 8:00＝480分、締め日 nil＝月末締め）を返す。
  - 深夜帯の定数（22 時・5 時）もここに置いた。
  - F6 では `WorkRules.current` が保存した設定を返すように変えればよい。勤怠履歴の画面・集計は `WorkRules.current` からだけ値を受け取る（`MonthlyAttendance` には `rules:` を引数で渡す）。
- **月度** `app/models/attendance_period.rb`
  - 「1か月」の範囲を表す。月末締めなら 1日〜末日、締め日がある場合（例：20日締め）は「11月度＝10/21〜11/20」。前月・翌月・URL 用の文字列（`2026-11`）・見出し（「2026年11月」、締め日ありなら「2026年11月度」）を持つ。
  - 締め日ありの計算は F6 の準備としてモデルテストだけで確認した（画面には出ていない）。
- **1日の計算**（`Attendance` に追加。実働は既存の `worked_minutes` をそのまま使う）
  - `overtime_minutes(scheduled_minutes:)`：実働のうち所定を超えた部分。所定ちょうどは 0。
  - `night_minutes`：出勤〜退勤と、各日の 22:00〜翌5:00 の重なり。深夜帯にかかる休憩は重なった分だけ引く。秒は実働と同じく切り捨て。前日 22:00〜当日 5:00 の帯（早朝出勤）と、長い勤務で2つの深夜帯にかかる場合も数える。
  - `missing_clock_out?`：退勤が無く、出勤から 24 時間（`TimeClock::MAX_SHIFT_DURATION`）を過ぎた勤務。ホーム画面の「退勤の打刻がない勤務」と同じ基準。
- **月の勤怠表** `app/models/monthly_attendance.rb`
  - 月度の全日付を1行ずつ（勤務の無い日も行を作る）。各行の状態は 勤務なし／勤務中／休憩中／退勤済み／退勤漏れ。
  - 合計は「日ごとの分」を足す（出勤日数・総実働・総残業・深夜・休憩）。残業は日ごとに出した値の合計で、ある日の不足と別の日の残業は相殺しない。
  - 退勤漏れの日は時間を計算できないので合計に入れない（出勤日数には入れる）。勤務中・休憩中の日は表示した時点までの時間を入れる。
- **画面** `GET /attendances`（`?month=2026-10` で月を指定。指定が無ければ今月）
  - `AttendancesController#index`。指定した月が不正（`2026-13`、`abc`、2000〜2100年の範囲外）なら、今月の画面へ移動して赤いメッセージを出す。
  - 見出し「2026年11月」＋「今月」バッジ、期間「11/1(日)〜11/30(月)」、「← 前月」「翌月 →」、今月以外のときは「今月」ボタン。
  - 「この月の合計」カード：出勤日数（「3日」）・総実働時間・総残業時間・深夜時間を大きな数字で表示。残業と深夜の定義（所定 8:00 も表示）を注記した。合計は `format_duration` で「160:30」のように時を 24 で繰り上げない。
  - 退勤漏れがあれば赤いお知らせ枠（「退勤漏れが N 日あります」＋日付一覧＋合計に入れていない理由）。勤務中・休憩中の日があれば緑の注記（「合計には表示した時点（HH:MM）までの時間を含めています」）。
  - 日別の表：日付／出勤／退勤／休憩／実働／残業／深夜／備考。
    - 勤務の無い日は空欄の行。土曜は青、日曜は赤の淡い背景で、日付の文字色も変える（表の上に凡例を表示）。今日の行は左端にティールの線と「今日」バッジ。
    - 日付をまたいで退勤した日は、退勤の前に「翌」（例：「翌02:00」）。
    - 退勤漏れの日は、赤い背景・左端の赤い線・退勤欄に赤字「未打刻」・備考に赤い「退勤漏れ」バッジ・時間の欄は「—」。
    - 0:00 の時間は薄い文字にして、時間がある欄を目立たせた。
  - 375px 以下では見出し行を隠し、1日を1枚のカード（日付の行＋出勤・退勤・休憩／実働・残業・深夜の 3 列×2 段。各値の上に欄の名前）にする。勤務の無い日は「11/3(火)　勤務なし」の1行に縮める。
  - ヘッダーのナビに「勤怠履歴」を追加（ホームの右。表示中は選択状態）。ホームの「アカウント」に「今月の勤怠履歴を見る」、ホームの退勤漏れのお知らせに「勤怠履歴で確認する」リンクを追加。
- **スプリント4評価の軽微な指摘1（`DEV_NOW` の注意書きの時刻が進まない）**
  - 注意書きの日付と時刻を時計（`clock` コントローラ）で毎秒進めるようにした（秒まで表示）。
  - 時計には「日付が変わったら画面を読み込み直す」動きがあるため、値 `reload-on-date-change` を追加し、注意書きでは無効にした（ホーム以外の画面が0時に勝手に読み込み直されないように）。ホームの動きは変わらない。

## 既知の問題・懸念

- **「退勤漏れ」の基準**：仕様は「退勤打刻が無いまま日付が過ぎた過去の勤務日」だが、ホーム画面（F3）では出勤から 24 時間以内ならまだ退勤できる。両画面の矛盾を避けるため、出勤から 24 時間以内の勤務は日付が過ぎても「勤務中」と表示し、24 時間を過ぎたら「退勤漏れ」にした（例：11/23 9:00 出勤のまま、11/24 8:00 に見ると「勤務中」、9:00 を過ぎると「退勤漏れ」）。仕様の解釈として確認してほしい。
- **退勤漏れの日の扱い**：時間は合計に含めず、出勤日数には含める。F14（月次集計）でも同じ扱いにするかは、そのとき決める必要がある。
- **勤務中の日の時間**：表示した時点の値で、ホームのように毎秒は進まない（再読み込みで更新）。合計にも表示時点までの時間が入る（注記あり）。
- **日曜と退勤漏れの色**：どちらも赤系。退勤漏れは濃い背景・赤線・バッジ・「未打刻」で区別しているが、色覚によっては背景色だけでは見分けにくい。
- **締め日ありの月度**：`AttendancePeriod` と `WorkRules` は対応済みだがモデルテストだけで確認しており、画面での確認は F6 でルールを保存できるようになってから。締め日ありのときの見出しは「2026年11月度」になる。
- **年の範囲**：URL で指定できるのは 2000〜2100 年。範囲の端では前月・翌月のリンクを出さない。
- 開発サーバー＋Playwright での目視確認はしていない（headless Chrome の system テストとスクリーンショット、curl のみ）。

#### 既知の問題・懸念（修正後）
- **夜勤の勤務中も履歴では赤い「退勤漏れ」になる**：22:00 出勤で翌 01:00 に履歴を見ると、正常な勤務中でも赤い印が付く（評価の改善点どおりの仕様解釈。「ホームで退勤可」の案内を添えている）。夜勤のある職場では驚かれる可能性があるため、気になる場合は仕様の判断として確認してほしい。
- 退勤漏れの日（24時間以内を含む）の時間は合計に一切入らない。「仮の時間」を別に出すことはしていない。
- 期限の表示は分までで、実際の期限は出勤時刻の秒まで（例：10:00:08 出勤なら 10:00:08 まで退勤可。表示は「10:00 まで」）。
- 375px での退勤可の案内の見た目は、自動テストの範囲外（備考欄はカード下段の全幅に出る想定）。
